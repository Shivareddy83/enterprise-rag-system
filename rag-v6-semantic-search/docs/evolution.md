# Evolution

## Version 5

### Problem

The system could generate embeddings and store them inside ChromaDB.

### Limitation

Users could not search the stored knowledge.

### Solution in Version 6

Introduce semantic search using vector similarity.

------------------------------------------------------------

## Version 6

### New Features

- Query embedding generation.
- Semantic similarity search.
- Top-K retrieval.
- Ranked search results.
- Natural language search.

### Benefits

- Intelligent document retrieval.
- Faster information discovery.
- Better search accuracy.
- Foundation for Retrieval-Augmented Generation (RAG).

------------------------------------------------------------
