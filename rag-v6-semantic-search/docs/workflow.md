# Workflow

## Version 6 – Semantic Search

1. User enters a natural language query.

2. The query is converted into a semantic embedding.

3. ChromaDB receives the embedding.

4. Vector similarity search is performed.

5. Top-K relevant chunks are retrieved.

6. Results are ranked according to similarity score.

7. Retrieved chunks are displayed to the user.

8. The workflow ends.

Future Version:

Version 7 will send these retrieved chunks to a Large Language Model to generate a final answer.
