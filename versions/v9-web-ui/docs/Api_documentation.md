# Introduction

The Enterprise Knowledge Platform (EKP) exposes a RESTful API built with **FastAPI**.

The API acts as the communication layer between the Enterprise Web UI and the AI-powered backend. It receives user requests, processes them through the Retrieval-Augmented Generation (RAG) pipeline, and returns structured JSON responses.

---

|----------|-------|
| Framework | FastAPI |
| API Style | REST |

## 3. Ask Question

### Endpoint

```
POST /ask
```

### Description

Accepts a user question, retrieves relevant document context, sends the prompt to Google Gemini, and returns an AI-generated response.

---

### Request Headers

```http
Content-Type: application/json
```

---

### Request Body

```json
{
    "question": "Explain FastAPI."
}
```

---

### Request Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| question | String | Yes | User question |

---

### Processing Steps

1. Validate request
2. Generate query embedding
3. Search ChromaDB
4. Retrieve relevant chunks
5. Build prompt
6. Send prompt to Gemini
7. Receive AI response
8. Return JSON response

---

### Success Response

```json
{
    "answer": "FastAPI is a modern Python framework for building high-performance APIs."
}
```

---

### Status Codes

| Code | Description |
|------|-------------|
| 200 | Success |
| 400 | Invalid Request |
| 500 | Internal Server Error |
