# Assets

This directory contains the visual resources used throughout the Enterprise Knowledge Platform (EKP) project.

## Structure

### logo/

Project logos and favicon.

### screenshots/

Application screenshots used in the README and documentation.

### architecture/

Architecture diagrams exported as images.

### diagrams/

Editable Draw.io source files.

### icons/

Custom icons used by the frontend.

### banners/

GitHub and social media banners.

### demo/

Animated GIFs and videos demonstrating the application.

---

## Guidelines

- Use PNG for screenshots.
- Use SVG for icons whenever possible.
- Keep image sizes optimized.
- Maintain consistent naming conventions.
- Update screenshots after major UI changes.

---

## Recommended Resolution

| Asset | Resolution |
|--------|------------|
| README Banner | 1600 × 600 |
| GitHub Social Preview | 1280 × 640 |
| Screenshot | 1920 × 1080 |
| Logo | 512 × 512 |
| Favicon | 32 × 32 |

---

## Naming Convention

Examples:

```
home-page.png
chat-interface.png
rag-pipeline.png
system-architecture.png
```

Use lowercase letters and hyphens for file names.
