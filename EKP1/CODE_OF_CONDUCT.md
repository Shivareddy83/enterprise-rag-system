# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for everyone.

## Expected Behavior

- Be respectful.
- Be constructive.
- Accept feedback.
- Help new contributors.

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discrimination
- Spam
- Trolling

## Enforcement

Project maintainers may remove contributions that violate this Code of Conduct.
